# 🏁 SprintTrack

Welcome to **SprintTrack** — a curated collection of focused, functional Spring Boot mini-projects. Each branch in this repository represents a unique backend project, designed for hands-on learning and practical experience.

---

## 🧠 Why SprintTrack?

This repo was built to:

- Sharpen real-world backend development skills  
- Practice RESTful API design using Spring Boot  
- Simulate realistic app building using layered architecture  
- Learn by building — not just reading

---

## 📚 Project Branches

| Branch Name       | Description                                           |
|-------------------|-------------------------------------------------------|
| `About`           | Project overview and documentation                   |
| `ToDoList`        | Simple to-do task manager with full CRUD             |
| `HostelReservation` | Hostel room booking system with student registration |
| `ParkingSystem`   | Smart parking system with waitlist and slot tracking |
| `RestaurantSystem`| Menu browsing and order cart API                     |
| `TicketBooking`   | Minimal ticket booking app with view and cancel APIs |

> 💡 Use the branch switcher on GitHub to explore each project individually.

---

## 🛠 Tech Stack

- Java 17+
- Spring Boot 3.x
- Maven for build and dependency management
- No external databases unless specified (most apps use in-memory lists)
- Tested using Postman / Swagger UI

---

## 🔍 What's Inside?

Each project is:

- Self-contained and runnable
- Follows proper layered structure (Controller → Service → Model)
- Uses realistic naming, formatting, and code style
- Well-documented with its own `README.md`
